# 🖋️ Nové Hanami vzory pro psací písmena

## Co je změněno

- **`pismena.html`** (1. třída) — obrázky psacích písmen v cvičení "Psací — obtahování" nahrazeny novými Hanami vzory se šipkami
- **`hlasky.html`** (2. třída) — obrázky psacích písmen v cvičeních "Psací písmo — poznávání" a "Psaní písmen — obtahování" nahrazeny novými Hanami vzory se šipkami

## Bonus v hlasky.html

Přidána **8. sada** pro Psací obtahování: **Č, Ď, Ň, Ř, Š, Ť, Ž** — všechna písmena s diakritikou najednou.

## Nasazení

V repu **github.com/LinguaUniversal/LinguaCzech**:
1. Otevři `pismena.html` → tužka (Edit) → smaž (nebo přepiš)
2. `Add file → Upload files` → přetáhni nový `pismena.html`
3. Totéž pro `hlasky.html`
4. Commit: `Nové Hanami vzory pro psací obtahování`

Po 1-2 min zkontroluj v anonymním okně:
- linguauniversal.github.io/LinguaCzech/pismena.html
- linguauniversal.github.io/LinguaCzech/hlasky.html

## Statistika

- Ve **staré verzi**: cca 50 obrázků, bez šipek směru tahu
- V **nové verzi**: 67 obrázků včetně diakritiky (Ď, Ň, Ř, Š, Ť, Ž velké i malé + q, w, x malé), **s barevnými šipkami** ukazujícími směr tahu

## Body žáků

- **Zachovány** — používají se stejné `localStorage` klíče (`pismena_score`, `hlasky_score`).
